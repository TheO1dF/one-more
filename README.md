# One More？ · v0.8.1

在线试玩：[itch.io](https://theoldf.itch.io/one-more) · [GitHub Pages](https://theo1df.github.io/one-more/) · [Cloudflare](https://one-more.theoldf2077.workers.dev/)。[公开发布仓库](https://github.com/TheO1dF/one-more)保存网页版发行文件。

双击「打开 One More.cmd」，或打开 http://127.0.0.1:8888/ 。本地开发运行需要 Node.js；发布后的网页版直接在浏览器游玩。

首次进入按系统时区默认选择中文或英文：中国大陆、香港、澳门和台湾时区默认中文，其余默认英文。不调用定位或网络服务；设置中可以切换，已保存的手动选择优先。

一个输光了一切的赌徒，接受赌场陌生人的最后一次邀局。十张牌桌，越来越多的炸弹。你能决定什么时候收手，却总想再来一次。

## 开始游玩

首次入座播放三段可跳过的短剧情，然后进入可操作教学。戴礼帽、微笑面具的陌生人引导翻牌、配对和查看；第一次教学会真的翻出炸弹并死亡。“再来一局”从零开始，随后学习收摊、掷骰、选路线、拿牌，到第二桌转为自由游玩。死亡及教学进度可续存；完成或跳过本版教学后不再自动出现。

主菜单只保留入座、继续、图鉴和设置；继续仅在有未结束的局时出现。语言、音乐、音效、动画、全屏和规则在设置中。桌上的当前牌组、垃圾桶、遗物和记录保留。

v0.8.0 保留现有正常存档与偏好，不重复执行 v0.6.0 的旧测试数据清理。旧试桌、骰子测试、起始牌组模式不在正式资源中；开发测试数据位于 test/，不打入游戏。

手机竖屏使用独立布局：顶部集中分数与牌堆，底部保留翻牌、收摊和卡牌详情操作。桌上最多两行，更多牌通过箭头或横向拖动翻页，支持跟手移动、松手滑入、短拖与边界回弹，不随牌数增加继续缩小。横屏改为侧边分数栏与一排大牌。图鉴和离桌收进设置，当前牌组仍可直接打开。

## 卡牌与牌局

80种卡牌，63组构筑包，每组至少包含1张麻烦。图鉴支持食材、工具、装置、麻烦分类；完整中英卡表见 [CARDS.md](CARDS.md)。

初始20张：14张食材、4件工具、1件装置、1张炸弹。普通食材2分，配对后4＋4。首桌目标8分，十桌一局。通常每桌第一张翻牌安全；教学第一桌采用引导牌序，其后恢复正常随机。

收摊将桌面分数装袋；累计不足目标即失败。第1至9桌依次掷骰增加下桌目标、二选一路线、必选一组牌；第10桌达标通关。附魔包括生腌、油炸、水煮；回收摊消耗4分已装袋分数删牌。

第四桌收摊后出现“子夜”事件：从第五桌起掷两颗 d20，以点数之和增加目标。取消前32张限制，炸弹可以在整个牌堆中。

以初始19张永久非炸弹牌为基准，每增加20张，在下一桌开局追加一枚炸弹：永久非炸弹牌达到39／59／79张时，炸弹总数至少为2／3／4枚。临时生成物不计入；已加入的炸弹不可删除，删牌不退还。牌组面板显示距下一枚还差几张，构筑包提前提示是否触发追加。新桌第一张仍安全，局内洗牌不恢复保护。比较结果见 [BALANCE.md](BALANCE.md)。

- d20=1：目标+1，加入赊账单、生锈、纸团；锁定。
- 2–5：目标增加骰点，加入纸团。
- 6–14：仅增加目标。
- 15–19：目标增加骰点，任选查看3张、1张临时万能酱、前2次工具食材费用为0。
- d20=20：目标+20，下桌获得12分临时盛宴；锁定。

以上低点数惩罚逐颗计算；高点数奖励每次结算最多一份，盛宴优先。双骰中的自然1／20各自锁定，其余骰子可以重掷一次；两颗都锁定则不能重掷。消耗食材不会自动产生残渣；只有卡面明确写出生成残渣的效果才会生成。详细结算见 [RULES.md](RULES.md)，体系见 [SYSTEMS.md](SYSTEMS.md)。

## 音乐

原创循环爵士《The Empty Glass》：76 BPM、32小节，约101秒。Rhodes电钢琴、步行贝斯、颤音琴旋律和轻鼓组。乐句在属和弦后回到起点。

原创MIDI已在 Online Sequencer 导入、设置配器并校正速度。网站的 MIDI/WAV 导出未返回可取得的文件；随游戏附带的是同一原创乐谱的本地合成版本，不依赖网站加载或第三方采样。来源与编辑文件见 [game/audio/README.md](game/audio/README.md)。

音乐在第一次点击或按键后开始，可独立开关和调音量；隐藏页面时暂停，返回后恢复。
