# One More?

A free, playable push-your-luck deckbuilding prototype. One more card, or one more run?

Flip cards from a hidden deck, build pairs and tool combinations, then cash out before a bomb ends your run. Ten tables, 80 card types, branching events, food enchantments and escalating d20 targets.

Play in a desktop or mobile browser. English and Simplified Chinese; the first visit selects a default from the system time zone, and Settings lets you switch at any time. Progress is stored only in your browser. No account or backend is required.

Version 0.8.1. This is an in-development prototype, not a finished release. Game design by TheO1dF; development, writing and visual assets were created with AI assistance. The cover illustration uses generative AI. Music: original composition "The Empty Glass".

This repository contains the distributable HTML5 build. Serve its root with any static HTTP server. No build step is required.
