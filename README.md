# One More？ · v0.5.0

双击 **打开 One More.cmd**，或打开 <http://127.0.0.1:8888/?v=050>。需要本机 Node.js，游戏资源不请求外网。

## 80种卡牌

图鉴现有80种卡牌，包含44种新增牌；新增牌都可通过轮末构筑取得。共63组构筑包，每组至少包含1张麻烦。图鉴提供全部80、新增44、食材、工具、装置、麻烦筛选。完整中英卡表见 [CARDS-v050.md](CARDS-v050.md)。

菜单“试新牌”提供六张可直接操作的主题桌：成双上菜、循环后厨、自助冷盘、开工时间、临时变常驻、鲜榨与爆米花。试桌不覆盖正式挑战存档。

- 配对：豆腐增加下一次食材生成数量；虾仁发现临时工具；面条让横置工具计分；奶酪复制散食材。
- 消耗：鸡蛋生成饭团、梨查看2张、砧板积累分数、漏勺取回消耗食材。
- 收藏：曲奇看同名数量奇偶、棉花糖奖励独有、沙拉看食材种类、蛋糕看对子数量。
- 工具：蒸笼留住下次被消耗的食材、菜刀把对子换成三张饭团、磨刀石允许工具连用、采购袋把临时食材收入牌组。
- 麻烦：积垢惩罚工具使用、杂物按工具数扣分、果蝇压制临时食材、冷灶关闭食材牌面的配对能力。

普通消耗不会自动生成残渣。榨汁机与烤架明确注明生成残渣；其他消耗按卡面结算。规则与触发次序见 [RULES.md](RULES.md)。

## 十桌挑战

普通食材2分，配对4＋4；首桌目标8分。初始20张：14食材、4工具、1装置、1炸弹。首张正式翻牌安全，之后炸弹不会被隐藏保护移动。

收摊把桌面分数装袋，不足累计目标会失败。第1至9桌依次确定d20目标、二选一路线、必选一组牌；第10桌结算通关。附魔包含生腌、油炸、水煮；回收摊消耗4分装袋分数删牌。

| d20 | 接受后 |
| --- | --- |
| 1 | 目标+1，加入赊账单、生锈、纸团，锁定 |
| 2–5 | 目标增加骰点，加入纸团 |
| 6–14 | 仅增加目标 |
| 15–19 | 目标增加骰点，选择查看3张、1张临时万能酱或前2次工具食材费用为0 |
| 20 | 目标+20，下桌12分临时盛宴，锁定 |

其他结果可以重掷一次。旧局可继续，未来的构筑包从新卡池抽取，已确定的旧选项保留。

## 运行与验证

npm run check 检查规则并构建；构建版由 scripts/serve.mjs 在本机8888端口提供。依照 AGENTS.md 使用独立 Microsoft Edge 检查手机与PC、中英文界面及实际完整十桌流程。

v0.5.0报告位于 .artifacts/smoke-one-more-v050/，分数模拟位于 .artifacts/balance-v050/。模拟采用确定性策略，不代表真实玩家胜率。

本轮113项规则测试、1454项界面检查通过；完整十桌实际点击103次，以90／86分通关。保存104张界面截图。另完成6组各500局的策略模拟，新增主动工具的组合强度仍需玩家反馈。
