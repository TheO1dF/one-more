# One More？ · v0.4.4

双击 **打开 One More.cmd**，或访问 <http://127.0.0.1:8888/?v=044>。需要本机已安装的 Node.js，游戏资源不请求外网。进行中的旧存档可继续；要体验新的首桌目标，请开新局。

## 本轮改动

- 主菜单新增“试新牌”，直接体验可乐、冰箱、榨汁、残渣处理、消耗装袋分数复制和爆米花配对。
- 新增7张构筑牌、2张生成牌；卡池共36种。
- 高目标奖励：开局查看3张、前2次工具食材费用为0、1张临时万能酱；自然20盛宴为12分。
- 消耗食材不自动生成残渣，只有明写生成残渣的效果才生成；当前为榨汁机。
- 消耗统一用词，卡牌、附魔、奖励、记录与中英文操作提示同步更新。
- 轮末先从两条岔路选一条：附魔、临时援助，或偶尔出现的消耗分数删牌。
- 生腌、油炸、水煮永久附在一张食材上；当前牌组显示附魔数量。
- 回收摊消耗4分装袋分数，永久删除一张非炸弹牌。
- 添牌改为必须三选一；每组都包含麻烦。
- 分拣夹改为备餐夹，从牌组外三个食材候选中选一张临时上桌。
- 顶栏新增独立的“当前牌组”按钮，仅展示实际拥有的永久牌及数量；完整卡池另见“图鉴”。
- 筛网可直接查看未知顶牌，再选择保留或弃置非炸弹牌。
- 进行中的五轮旧存档会延长为十轮，原有分数、牌序与进度保留；新局从8分开始。
- 设计方向与已实装内容见 [SYSTEMS.md](SYSTEMS.md)。

- 食材2分，配对4＋4；首桌目标为8，之后每桌仍增加原始d20点数。
- 默认20张牌改为14食材、4工具、1装置、1炸弹。初始不放入需要先抓麻烦才能发挥作用的工具。
- 36种卡牌保留一句话效果，去掉猜下一张类型的条件链，改为主动选择、入桌收益、持续规则和配对触发。
- 收摊和One More放在桌面下方中央、相互紧邻；One More面积更大、颜色更亮。
- 标题居中；骰子界面明确标示“下桌目标”“目标增加”，另列已装袋分数。
- 炸弹有翻出、引线、爆炸、碎片、烟尘与音效，支持跳过和简化动画。
- 保留真实横置、卡牌自动缩放、最多四行后分页、拖入骰盘、中英文和全屏。

## 换桌

共十桌，收摊将桌面分数装袋，多余分数可以抵扣之后的累计目标。未达到目标时收摊会失败，界面先确认。第1至9桌结束后，确定骰子目标 → 二选一路线 → 必须选一组牌 → 下一桌。添牌无需消耗额外分数，每组都包含麻烦。第2、5、8桌后可能遇到回收摊，分数足够才能出现，走另一条路则不删牌。第10桌结算通关。

| d20 | 接受后 |
| --- | --- |
| 1 | 目标+1；永久加入赊账单、生锈、纸团；锁定 |
| 2–5 | 目标增加骰点；永久加入纸团 |
| 6–14 | 仅增加目标 |
| 15–19 | 增加目标，并选择下桌查看3张、1张临时万能酱或前2次工具的食材费用为0 |
| 20 | 目标+20；下桌获得饭团对子、鱼干与薄荷，共12分；锁定 |

其他点数可重掷一次。每桌第一张安全，中途重洗不恢复首张保护。

v0.4.3历史分数测试见 [BALANCE-v043.md](BALANCE-v043.md)；当前残渣与奖励规则见 [RULES.md](RULES.md)。

## 运行与验证

`npm run check` 检查规则并构建。`npm start` 启动本地入口。构建版可用 `node scripts/serve.mjs 8888 dist 127.0.0.1`。

依照AGENTS.md使用独立Microsoft Edge。`scripts/browser-smoke.mjs` 检查1280×800中文、1920×1080英文、960×600中文、390×844英文；`scripts/full-run-smoke.mjs` 实际点击完整十桌。默认调试端口9227。

80项规则测试、904项界面检查通过；完整十桌实际操作140次，106／99分通关。覆盖四种屏幕尺寸、中英文、三种高目标奖励，以及消耗与残渣的实际结算。结果保存于 `.artifacts/smoke-one-more-v044/`。历史分数模拟保留在 `.artifacts/balance-v043/`，不作为当前规则的模拟结果。
