## 开始游玩

首次入座播放三段可跳过的短剧情，然后进入可操作教学。戴礼帽、微笑面具的陌生人引导翻牌、配对和查看；第一次教学会真的翻出炸弹并死亡。“再来一局”从零开始，随后实际使用摇签筒避开已知炸弹，再学习收摊、掷骰、选路线、拿牌，到第二桌转为自由游玩。死亡及教学进度可续存；完成或跳过本版教学后不再自动出现。

主菜单提供入座、继续、图鉴、解锁簿和设置；继续仅在有未结束的局时出现。语言、音乐、音效、动画帧率、全屏和规则在设置中。桌上的当前牌组、垃圾桶、抵押物和记录保留。

v0.8.0 保留现有正常存档与偏好，不重复执行 v0.6.0 的旧测试数据清理。旧试桌、骰子测试、起始牌组模式不在正式资源中；开发测试数据位于 test/，不打入游戏。

手机竖屏使用独立布局：顶部集中分数与牌堆，底部保留翻牌、收摊和卡牌详情操作。桌面为连续横向长牌列，原生滑动、不分页，不随牌数增加继续缩小。横屏改为侧边分数栏与一排大牌。图鉴和离桌收进设置，当前牌组仍可直接打开。

## 卡牌与牌局

80种卡牌、20件抵押物。9个里程碑逐步开放卡池、抵押物、4款卡背、旧版卡图、4档难度和3种挑战；解锁不增加永久属性。初始可用48种卡牌定义与8件抵押物，新卡池从下一局生效。构筑包均包含麻烦，实际候选由当前解锁池决定。

初始20张：14张食材、4件工具、1件装置、1张炸弹。普通食材2分，配对后4＋4。首桌目标8分，十桌一局。通常每桌第一张翻牌安全；教学第一桌采用引导牌序，其后恢复正常随机。

收摊将桌面分数装袋；不足目标即失败。新局的下桌目标为“原目标＋骰子＋进阶加码”，保留前期贪分带来的余地；旧进行中存档保留原有底注规则。第1至9桌依次掷骰增加下桌目标、二选一路线、必选一组牌；第10桌达标通关。附魔包括生腌、油炸、水煮；回收摊消耗4分已装袋分数删牌。

从第五桌起掷两颗 d20，以点数之和增加目标；进阶1第八桌起三骰，进阶2另加阶段目标2／4／8，进阶3缩短新增炸弹间隔至15张永久非炸弹牌。没有前32张限制，炸弹可以在整个牌堆中。

以初始19张永久非炸弹牌为基准，每增加20张，在下一桌开局追加一枚炸弹：永久非炸弹牌达到39／59／79张时，炸弹总数至少为2／3／4枚。临时生成物不计入；已加入的炸弹不可删除，删牌不退还。牌组面板显示距下一枚还差几张，构筑包提前提示是否触发追加。新桌第一张仍安全，局内洗牌不恢复保护。比较结果见 [BALANCE.md](BALANCE.md)。

- d20=1：目标+1，加入赊账单、生锈、纸团；锁定。
- 2–5：目标增加骰点，加入纸团。
- 6–14：仅增加目标。
- 15–19：目标增加骰点，任选查看3张、1张临时万能酱、前2次工具食材费用为0。
- d20=20：目标+20，下桌获得12分临时盛宴；锁定。

以上低点数惩罚逐颗计算；高点数奖励每次结算最多一份，盛宴优先。双骰中的自然1／20各自锁定，其余骰子可以重掷一次；两颗都锁定则不能重掷。消耗食材不会自动产生残渣；只有卡面明确写出生成残渣的效果才会生成。详细结算见 [RULES.md](RULES.md)，体系见 [SYSTEMS.md](SYSTEMS.md)。

## 音乐

原创循环爵士《The Empty Glass》：76 BPM、32小节，约101秒。Rhodes电钢琴、步行贝斯、颤音琴旋律和轻鼓组。乐句在属和弦后回到起点。

原创MIDI已在 Online Sequencer 导入、设置配器并校正速度。网站的 MIDI/WAV 导出未返回可取得的文件；随游戏附带的是同一原创乐谱的本地合成版本，不依赖网站加载或第三方采样。来源与编辑文件见 [game/audio/README.md](game/audio/README.md)。

音乐在第一次点击或按键后开始，可独立开关和调音量；隐藏页面时暂停，返回后恢复。

## 构建与发布

`npm run build` 生成不含成长实验的正式 `dist/`；`npm run check` 检查规则、构建并验证正式内容边界。成长实验只在源码入口或显式 `npm run build:playtest` 生成的 `dist-playtest/` 中保留。公开发行分支 `main` 的根目录已经是静态网站，无需构建；只同步 `dist/`，不可直接复制源码 `game/` 或 `dist-playtest/`。不要将测试存档、`.artifacts/` 或 `node_modules/` 上传到网站。

Windows 包装在 `pc-steam` 的 `desktop/`；当前便携式 EXE 已完成本机验证。Steam 计划先开放免费 Playtest；用户的 Steamworks 税务资料正在审核（2026-09-20），尚未提供游戏 AppID，商店素材目前仍是本地准备包。
