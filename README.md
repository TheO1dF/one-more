# One More？ · v0.2.0

一张永远留在牌库里的炸弹，一桌可以彼此借力的卡牌。

点击食材寻找配对，花食材使用工具，利用翻出顺序与延迟能力。见好就收，或者再翻一张。

双击本目录的 **打开 One More.cmd** 启动；当前本地入口为 <http://127.0.0.1:8888/>。需要本机已经安装的 Node.js。网页、卡图、骰子和声音全部来自本项目，无外部资源请求。

## 这一版

- 独立游戏目录与存档；保留米色卡面、柔和配色及原有 SVG 插画。
- 绿绒牌桌、木质桌沿、卡牌轻微错落。工具使用后整张卡旋转 90°，配对恢复后转回。
- 炸弹入堆、洗牌、翻牌飞入桌面、摇签筒重洗动画。
- 两颗有六个实体面的 CSS 3D 骰子，投掷、翻滚、弹跳、停稳。左十位，右个位。
- 27 种卡牌、16 组构筑包、4 件遗物；默认 20 张牌包含 16 种牌、10 张食材和唯一炸弹。
- 中文 / 英文、全屏、音效开关、简化动画、独立的配对和骰子练习。

## 目标与骰子

共五桌，首桌累计目标 30 分。食材通常单张 10 分，成对每张 20 分。桌面自动计算。

收摊时把桌面的分数装袋，累计达到当前目标即可继续。提前离桌但未达标会结束本局，界面会先询问。多赚的分数可抵扣下一桌需要赚的分数。

每次换桌掷两颗 d6，组成 11–66，累加到下一桌目标。接受 ≤23：永久加入一张纸团；接受 ≥51：选择仅下一轮生效的查看前三张、临时万能酱或两次免费工具费用。允许自愿重掷一次，替换旧结果。

每次换桌可免费加一组牌、删一张牌，各一次，也可以跳过。炸弹不可删除。每轮首张安全，之后没有隐藏保底；中途摇签重洗不恢复保护。

## 新的顺序组合

- **热茶**：紧接食材翻出，查看下一张；配对查看两张。
- **吐司**：紧接工具翻出，恢复该工具；配对取回一个为工具支付的食材。
- **接力铃**：食材之后紧接付费工具，给予该工具一次免费使用，每轮两次。
- **烛台**：连续两张麻烦，换取查看一次。
- **时刻表**：第 3 或第 6 次翻出时查看三张，否则一张。
- **预热炉**：首次翻出一种食材时加速最早的发酵，每轮两次。
- **筛网**：用食材换查看，滤掉顶端麻烦；不会翻出或滤掉炸弹。
- **姜片**：配对可先清理麻烦，再查看。
- **铁锈 / 干扰**：让下一件工具横置，或把查看延迟到下次真正翻牌后。

精确结算见 [RULES.md](RULES.md)。这是可玩的早期迭代，骰子阈值、分值和卡池比例仍需进一步实玩调整。

## 开发与验证

`npm run check` 运行规则测试并生成 `dist/`。`npm start` 启动本地开发入口；发布构建可用 `node scripts/serve.mjs 8888 dist 127.0.0.1`。

按 AGENTS.md 使用独立 Microsoft Edge 测试配置。启用调试端口后，运行 `node scripts/browser-smoke.mjs` 与 `node scripts/full-run-smoke.mjs`。默认端口 9227，可用环境变量 `EDGE_DEBUG_PORT` 覆盖。

本轮验证：37 项规则测试、266 项浏览器检查全部通过。覆盖 1280×800 中文、1920×1080 英文、960×600 中文、390×844 英文；完整五桌参考流程通过 48 次实际 UI 操作结束于 260 / 235 分。报告与截图位于 `.artifacts/smoke-one-more-v020/`。

参考方向为 [Balatro](https://www.playbalatro.com/) 的牌桌信息层级和 [万智牌](https://magic.wizards.com/en/news/feature/stack-and-its-tricks-2017-11-30) 对能力、事件与结算的区分。本游戏使用固定顺序事件队列，不使用万智牌的后进先出堆叠；没有使用其卡图、商标素材或游戏代码。
