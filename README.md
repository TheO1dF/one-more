# One More？ · v0.3.0

一张永远留在牌库里的炸弹，一桌可以彼此借力的卡牌。

双击 **打开 One More.cmd**，或打开 <http://127.0.0.1:8888/>。需要本机已安装的 Node.js；游戏不请求外部资源。本版使用新存档，请开新局，旧版存档不覆盖。

## 这一版

- 保留米色卡面、SVG 插画与绿绒牌桌，删去多余的常驻说明。
- 卡牌错落摆放，翻牌有动画，使用工具后整张横置。
- 桌面随牌数自动缩小卡牌，最多四行，更多卡牌用页码切换；桌内没有上下滚轴。点选小卡可看完整效果。
- 一颗真正的二十面骰：点击摇动，拖进木质骰盘投掷，也可以点“掷出”。骰子停稳后可拿起重掷一次，自然1／20锁定。
- 27 种卡牌均用一句话描述效果；顺序条件只关心紧接着翻出的下一张。
- 默认 20 张牌含 16 种牌、10 张食材和唯一炸弹；另有 16 组构筑包、4 件遗物。
- 中文／英文、全屏、音效、简化动画，以及配对和掷骰练习。

## 点数与换桌

食材单张 **1分**，配对后 **2＋2分**。共五桌，第一桌累计目标为3。收摊时把桌面分数装袋；累计达到目标才可继续，多赚的分数可抵扣之后的目标。

换桌掷一颗 d20，把结果累加到下一桌目标；先接受骰子，再构筑。

| 点数 | 效果 |
| --- | --- |
| 1 | 加入欠账、铁锈、纸团各一张；不能重掷 |
| 2–5 | 加入一张纸团 |
| 6–14 | 无额外效果 |
| 15–19 | 为下一桌选择：查看前三张、两张临时万能酱、两次工具免付食材 |
| 20 | 下一桌已有三组临时对子，共12分；不能重掷 |

每次换桌可免费加一组牌、删一张牌，各一次，也可跳过。炸弹不可删除。每轮第一张安全，之后没有隐藏保底；中途使用遗物重洗不恢复首张保护。

精确结算见 [RULES.md](RULES.md)，点数测试与待观察问题见 [BALANCE.md](BALANCE.md)。

## 开发与验证

`npm run check` 运行规则测试并生成 `dist/`。`npm start` 启动本地入口；构建后也可用 `node scripts/serve.mjs 8888 dist 127.0.0.1`。

按 AGENTS.md 使用独立 Microsoft Edge 测试配置。启用调试端口后，运行 `node scripts/browser-smoke.mjs` 与 `node scripts/full-run-smoke.mjs`。默认端口9227，可通过 `EDGE_DEBUG_PORT` 覆盖。

v0.3.0 已通过37项规则、几何和布局测试，429项浏览器检查；覆盖1280×800中文、1920×1080英文、960×600中文、390×844英文。完整五桌通过63次实际界面操作，结束于39／39分。报告和截图在 `.artifacts/smoke-one-more-v030/`。

`node scripts/balance.mjs 2000` 运行三种策略各2000局，结果在 `.artifacts/balance-v030/report.json`。这些是确定性策略探针，不代表玩家胜率。
