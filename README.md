# One More？ · v0.4.0

双击 **打开 One More.cmd**，或访问 <http://127.0.0.1:8888/?v=040>。需要本机已安装的 Node.js，游戏资源不请求外网。卡牌效果已经变化，本版请开新局，旧存档保留但不沿用。

## 本轮改动

- 食材2分，配对4＋4；首桌目标仍为3，之后每桌仍增加原始d20点数。
- 默认20张牌改为14食材、4工具、1装置、1炸弹。初始不放入需要先抓麻烦才能发挥作用的工具。
- 27种卡牌保留一句话效果，去掉猜下一张类型的条件链，改为主动选择、入桌收益、持续规则和配对触发。
- 收摊和One More放在桌面下方中央、相互紧邻；One More面积更大、颜色更亮。
- 标题居中；骰子界面明确标示“下桌目标”“目标增加”，另列已装袋分数。
- 炸弹有翻出、引线、爆炸、碎片、烟尘与音效，支持跳过和简化动画。
- 保留真实横置、卡牌自动缩放、最多四行后分页、拖入骰盘、中英文和全屏。

## 换桌

共五桌，收摊将桌面分数装袋，多余分数可以抵扣之后的累计目标。未达到目标时收摊会失败，界面先确认。每次换桌可免费加一组牌、删一张非炸弹牌，各一次。

| d20 | 接受后 |
| --- | --- |
| 1 | 目标+1；永久加入赊账单、生锈、纸团；锁定 |
| 2–5 | 目标增加骰点；永久加入纸团 |
| 6–14 | 仅增加目标 |
| 15–19 | 增加目标，并选择下桌查看前三张、两张临时万能酱或两次工具免付 |
| 20 | 目标+20；下桌获得三组已配好的临时对子，共24分；锁定 |

其他点数可重掷一次。每桌第一张安全，中途重洗不恢复首张保护。

卡牌与测试结论见 [BALANCE.md](BALANCE.md)，精确规则见 [RULES.md](RULES.md)。

## 运行与验证

`npm run check` 检查规则并构建。`npm start` 启动本地入口。构建版可用 `node scripts/serve.mjs 8888 dist 127.0.0.1`。

依照AGENTS.md使用独立Microsoft Edge。`scripts/browser-smoke.mjs` 检查1280×800中文、1920×1080英文、960×600中文、390×844英文；`scripts/full-run-smoke.mjs` 实际点击完整五桌。默认调试端口9227。

本版42项规则、几何与布局测试、465项界面检查通过；完整五桌通过32次实际操作，最终38／37分通关。界面报告与截图在 `.artifacts/smoke-one-more-v040/`。`node scripts/balance.mjs 2000` 运行六种设置共12000局，结果在 `.artifacts/balance-v040/report.json`。
