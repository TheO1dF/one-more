# Minimal character artwork

Flat SVG derivatives of the preserved world character studies and Pan v4. The game uses the same paths inline from game/character-art.js so head and hand groups can animate. These standalone SVG exports are for review and reuse.

No raster image is embedded. Original PNG studies remain in game/assets/world and game/assets/pan. Route choices use existing prop icons; portraits appear only on the home/tutorial and inside encounters.
