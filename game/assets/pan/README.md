# Pan · editorial v3

`pan-editorial-v3.png` is the current character illustration (1122 × 1402). Generated with the built-in image generation tool for One More?, using the user-provided casino poster as a palette and shape-language reference. The existing vector illustration remains as `panLegacyArt` in `game/pan-art.js`.

Art direction: an adult, worldly satyr casino guest with curled ram horns, a relaxed sideways posture and a thin gold wine coupe. Ivory dinner jacket, aubergine lapels, warm skin, deep navy background. Original mid-century cut-paper poster composition; angular flat shapes, restrained color areas, no text, no universal black outline. Avoid a mascot, childish proportions, front-facing symmetry or a generic fantasy wizard.

The current portrait is used in the encounter and interception presentation. Native SVG hands, cup, cracks and shards remain separate animated elements. The full image is referenced via an ES module URL so the normal build includes it.
